Für Lehrkräfte

Hier erzeugen Sie einen Link und einen QR-Code für Ihre Klasse. Die Schülerinnen und Schüler öffnen den Link oder scannen den Code und bestätigen einmal. Der Link enthält nur den Jahrgang und die Auswahl der Stufen – keine Namen, keine Ergebnisse. Nichts verlässt das Gerät. Auf diesem Gerät ändert sich durch diese Seite nichts.

Was ist dran?

Eigene Auswahl: Im Link stehen nur die Abweichungen von der Voreinstellung.

Auf den Geräten der Klasse ist danach alles bis zur gewählten Stufe sofort offen; darüber hinaus gilt weiter ‚frei ab 8 von 10‘. Was einmal offen war, bleibt offen.
